# akram-portfolio-pro-v2 (fullpage.js)

## Run
```bash
npm i
npm run dev
```

- Next.js 14 + TS + Tailwind + Framer Motion + Sonner + Radix Tooltip
- Fullpage scroll via `fullpage.js` (anchors: #home, #portfolio, #clients, #contact)
- FR | EN switch (single button), animated header + footer on language change
- Minimal dark design, no scrollbars
- SEO: OG, JSON-LD, robots, sitemap, manifest
- Legal: Mentions légales, CGU/CGV, Cookies, 404
